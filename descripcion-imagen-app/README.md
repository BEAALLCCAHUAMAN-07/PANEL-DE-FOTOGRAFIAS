# 📷 Descripción de Imágenes con IA

Aplicación web desarrollada en Python que permite subir una imagen y obtener una descripción automática generada por Inteligencia Artificial, además de permitir al usuario escribir su propia descripción.

## 🚀 Características

- ✅ Subir imágenes (JPG, PNG, JPEG)
- ✅ Descripción automática con IA (modelo BLIP de Salesforce)
- ✅ Campo de texto editable para escribir o modificar la descripción
- ✅ Interfaz amigable con Streamlit
- ✅ 100% gratuito y de código abierto

## 🛠️ Tecnologías utilizadas

- **Python 3.9+**
- **Streamlit** - Framework para la interfaz web
- **Transformers (Hugging Face)** - Modelo de IA BLIP
- **PyTorch** - Motor de deep learning
- **Pillow** - Procesamiento de imágenes
